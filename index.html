Haybarn

An independent derived distribution of DuckDB · by Query Farm

curl https://query-farm-haybarn.github.io/install | sh

Installs the latest release to ~/.haybarn/cli/latest/haybarn and symlinks it into ~/.local/bin if available.
Supports Linux (x86_64, arm64) and macOS (x86_64, arm64).

Other install methods

Install a specific version
HAYBARN_VERSION=haybarn-v1.5.2-rc7 curl https://query-farm-haybarn.github.io/install | sh
Download the script first (inspect before running)
curl -o install.sh https://query-farm-haybarn.github.io/install && sh install.sh
